Layout Extension (Описание)
Layout — это статический класс-расширение для унифицированного абсолютного позиционирования элементов в Avalonia UI. Он позволяет управлять координатами контролов как программно, так и через визуальный редактор, независимо от типа родительского контейнера.

Основные возможности:
Универсальное позиционирование:

Позволяет задавать координаты X и Y для любого контрола.

Внутри Canvas использует нативные Canvas.Left / Canvas.Top.

В других контейнерах (Grid, StackPanel и др.) автоматически применяет TranslateTransform.

Гибридный режим работы (Read/Write):

Автоматический (Read-Only): Если элемент позиционируется системой компоновки (например, HorizontalAlignment="Center" или находится внутри StackPanel), свойства X и Y автоматически обновляются, отображая фактическую позицию элемента относительно родителя.

Ручной (Manual): При явном задании X или Y (или перетаскивании) выравнивание элемента автоматически переключается на Left / Top, чтобы обеспечить точное позиционирование в указанных координатах.

Интеграция с Дизайнером:

Свойства DesignX и DesignY предоставляют глобальные координаты элемента относительно корневого редактора (UiDesigner) или окна. Это упрощает реализацию перетаскивания (Drag-and-Drop) и отрисовку вспомогательных рамок (adorners).

Интеллектуальная обработка Stretch:

При попытке переместить элемент с выравниванием Stretch, класс автоматически фиксирует его текущие размеры (Width / Height) перед перемещением, предотвращая визуальное схлопывание контрола.
